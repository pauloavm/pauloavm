## 👤 Quem é Paulo Munhoz?

Sou um **Analista de Dados e BI** com **8+ anos** de experiência operando na interseção entre dados, tecnologia e resultados de negócio. Minha carreira começou no chão de fábrica e na rede comercial automotiva — onde aprendi **de onde o número realmente nasce** — e hoje aplico essa visão sistêmica para construir soluções analíticas que **aceleram decisões e geram ROI mensurável**.

**O que me diferencia:** a capacidade de ler um número não como uma métrica isolada, mas como reflexo de uma engrenagem operacional — seja uma linha de produção no ABC Paulista, seja um funil de vendas em uma concessionária.

## 🏆 Projetos de Portfólio (Sugestões Estratégicas)

Para recrutadores de São Paulo e do polo industrial do ABC, sugiro linkar projetos que demonstrem **dados industriais → inteligência comercial**:

1. **Dashboard de OEE e Eficiência Produtiva**
   * 📌 *Problema:* Perdas invisíveis no chão de fábrica.
   * 📌 *Stack:* Python (ETL) → Databricks (Silver/Gold) → Power BI.
   * 📌 *Impacto:* Simular como otimizar a produção pode reduzir custos em X%.

2. **Análise de Funil e Churn no Setor Automotivo**
   * 📌 *Problema:* Perda de leads e retenção de concessionárias.
   * 📌 *Stack:* SQL (DBT modeling) → Power BI (storytelling).
   * 📌 *Impacto:* Mostrar como elevar a conversão de +35% (caso Shineray).

3. **Forecast de Vendas com Sazonalidade**
   * 📌 *Problema:* Previsão de demanda para planejamento logístico.
   * 📌 *Stack:* Python (statsmodels/sklearn) → Databricks → Airflow (orquest.)
   * 📌 *Impacto:* Reduzir estoque parado e custos de armazenagem.

> 💡 *Dica estratégica:* Monte pelo menos 1 projeto end-to-end no GitHub usando a estrutura `raw → bronze → silver → gold` com DBT. Isso sinaliza ao recrutador de tech que você pensa em **arquitetura de dados**, não só em visualização.
