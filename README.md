Sou **Analista de Dados e BI** com **8+ anos** de experiência na interseção entre dados, tecnologia e resultado de negócio. Minha carreira começou no chão de fábrica e na rede comercial automotiva, onde aprendi **de onde o número realmente nasce**. Hoje aplico essa visão para construir soluções analíticas que aceleram decisões.
